# PocketLink Support

[Korean](./ko/) · [Privacy Policy](./privacy/#english)

PocketLink lets you stream and control your PC from an iPhone or iPad.

## Connect to a PC

1. Start Sunshine or a compatible host, such as Vibeshine, on the PC.
2. For local discovery, connect both devices to the same local network and allow PocketLink to access the local network in iOS Settings. If the PC is missing, use **Add PC** and enter its address. If you connect over a VPN, add its reachable VPN address manually.
3. Select the PC in PocketLink and enter the displayed PIN in the host's PIN page. Once paired, choose Desktop or another app offered by the host.

## Free and Pro

| Feature | Free | Pro |
| --- | --- | --- |
| Remote PC control | Touch, keyboard, mouse, and gamepad | Same controls |
| Streaming | Up to 1080p and 60 fps | Higher resolutions and frame rates, HDR, and 4:4:4 chroma |
| On-screen gamepad layout | Move and resize the default controls | Also add controls and customize advanced button actions |
| Macros | Unavailable | Available |
| Picture in Picture and remote drawing | Unavailable | Available |
| Ads | Included | Removed |

Video options depend on the device, host, and selected codec. Pro is a one-time in-app purchase.

## Get help

- **Connection or pairing.** Check that the host is running, the address is correct, and both devices can reach each other. If pairing fails after you reinstall PocketLink, try pairing again. If the host reports that another app is running, resume it or end it using the available session options before starting a different app.
- **Pro purchases.** Pro is a one-time in-app purchase. If Pro is missing after reinstalling or changing devices, open **Settings → PocketLink Pro → Restore Purchases** with the Apple Account used to buy it. Submit refund requests through Apple. [Apple refund requests](https://reportaproblem.apple.com/)
- **Bugs and suggestions.** Include the PocketLink version, iPhone or iPad model, OS version, host name and version (for example, Sunshine and its version), and the steps you followed. GitHub issues are public. Leave out PC addresses, device names, PINs, credentials, and screenshots or logs that contain personal information. [Open a public issue](https://github.com/JDAnything/pocketlink-support/issues/new/choose)
- **Private support and ad reports.** Email us for purchase, privacy, or account-related questions or to report an inappropriate ad. For an ad report, include when and where it appeared, and its advertiser or title if visible. [jjjjjjayda10@gmail.com](mailto:jjjjjjayda10@gmail.com)
